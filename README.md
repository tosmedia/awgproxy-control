# AWGProxy Control

Значок в строке меню macOS и в трее Windows для AWGProxy — локального прокси через туннель AmneziaWG ([wireproxy-awg](https://github.com/artem-russkikh/wireproxy-awg)).

- Цвет значка: зелёный — трафик идёт через туннель, жёлтый — туннель есть, системный прокси выключен, красный — сервер не отвечает или прокси без туннеля, серый — выключено.
- Включить / выключить VPN (туннель + системный прокси).
- «Сторож»: в любой сети сам включает системный прокси и перезапускает зависший туннель.
- Переключение профилей (серверов) с проверкой и откатом.
- Отчёт для диагностики (без ключей) — копируется в буфер обмена.
- macOS: «Строгий режим» — брандмауэр (pf, свой якорь) пропускает наружу только туннель к серверу, локальную сеть и DHCP; если сервер молчит, интернета нет ни у одной программы. Первое включение спрашивает пароль администратора (ставится служба `com.awgproxy.killswitch`), дальше — без пароля. Исключения — `killswitch-allow.txt` в папке AWGProxy. Аварийно снять: `sudo pfctl -a com.apple/250.AWGProxyKillSwitch -F all`.
- macOS: «Кто ходит мимо Армении?» — список программ, которые сейчас соединяются с интернетом напрямую, не через прокси.
- Автообновление из релизов этого репозитория (файл сверяется по SHA256SUMS).

В репозитории нет ключей, конфигов и адресов серверов: приложение работает с профилями, которые уже лежат на компьютере.

## Установка

**macOS (Apple Silicon):** скачать `AWGProxy-Control-mac-arm64.zip` из последнего релиза, распаковать, перетащить `AWGProxy Control` в «Программы» и открыть (первый раз: правый клик → «Открыть»). Значок появится справа в строке меню.

**Windows:** скачать `AWGProxy-Control-windows-amd64.exe`, положить, например, в `%LOCALAPPDATA%\AWGProxyControl\` и запустить. Один раз выбрать в меню «Настроить права».

## Сборка

Каждый push в `main` собирает обе версии на GitHub Actions (без cgo: значок macOS работает через Objective-C runtime, `tray/tray_darwin.go`) и публикует релиз `1.1.<номер сборки>`.
